React + Tailwind CSS (Vite) শর্ট নোট
১. নতুন React প্রজেক্ট তৈরি ও ফোল্ডারে প্রবেশ:
npm create vite@latest my-project -- --template react
cd my-project

NTOE: • --template react এর কাজ। এটি সরাসরি React-এর ফাইল ও সেটআপ তৈরি করে দেয়।
• না দিলে কী হয়? আপনি যদি শুধু npm create vite@latest my-project লেখেন, তবে কোনো এরর হবে না। কিন্তু টার্মিনালে আপনাকে নিজে থেকে সিলেক্ট করতে বলবে আপনি কোন ফ্রেমওয়ার্ক (Vanilla, Vue, React, Svelte ইত্যাদি) এবং কোন ল্যাঙ্গুয়েজ (JavaScript নাকি TypeScript) ব্যবহার করতে চান। সময় বাঁচানোর জন্যই -- --template react ব্যবহার করা হয়।

২. Tailwind CSS ইনস্টল (সর্বশেষ সহজ পদ্ধতি - v4):

npm install tailwindcss @tailwindcss/vite

৩. vite.config.js ফাইলে প্লাগইন যুক্ত করা:
প্রজেক্টের vite.config.js ফাইলটি খুলে নিচের কোডটি পেস্ট করে সেভ (Ctrl + S) করুন:

import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})

৪. src/index.css ফাইলে Tailwind ইমপোর্ট করা:
src/index.css ফাইলের আগের সব লেখা মুছে শুধু নিচের ১ লাইন লিখে সেভ করুন:

@import "tailwindcss";

৫. প্রজেক্ট রান করা:

npm run dev

নতুন কোনো প্যাকেজ (npm install ...) বা .env ফাইল পরিবর্তন করলে 
টার্মিনালে Ctrl + C চেপে সার্ভার বন্ধ করে আবার npm run dev দিয়ে চালু করুন।

        Error মেসেজ দেখুন
      </button>
    </div>
  );

}

১. ব্রাউজার কনসোল (Browser Console) চেক করা — সবচেয়ে গুরুত্বপূর্ণ

কোডে কোনো ভুল হলে বা পেজ সাদা (Blank) হয়ে গেলে প্রথমেই এটি চেক করবেন:
• ওপেন করার নিয়ম। ব্রাউজারে আপনার প্রজেক্টের পেজে গিয়ে মাউসের ডান বাটনে ক্লিক করে Inspect সিলেক্ট করুন (অথবা কিবোর্ড থেকে F12 বা Ctrl + Shift + I চাপুন)।
• Console ট্যাব। উপরে Console ট্যাবে ক্লিক করুন। এখানে লাল রঙের লেখা দেখলে বুঝবেন কোডে কোনো এরর আছে।
• ফাইল ও লাইন নম্বর দেখা। লাল এরর মেসেজের ডানপাশে ফাইলটির নাম ও লাইন নম্বর (যেমন: App.jsx:15) লেখা থাকে, 
সেখানে ক্লিক করলে সরাসরি ভুল লাইনটি দেখতে পাবেন।

২. নেটওয়ার্ক ট্যাব (Network Tab) চেক করা — API বা ডাটাবেস এররের জন্য

ব্যাকএন্ড বা MySQL থেকে ডাটা না আসলে বা সাবমিট না হলে এটি চেক করবেন:
• Network ট্যাব ওপেন। Inspect প্যানেলের উপরে Network ট্যাবে ক্লিক করুন এবং নিচে Fetch/XHR অপশনটি সিলেক্ট করুন।
• স্ট্যাটাস কোড দেখা। বাটনে ক্লিক বা পেজ রিলোড করলে যে রিকোয়েস্টটি লাল রঙ হয়ে যাবে, সেটিতে ক্লিক করুন।
	• 404 Error: আপনার API-এর URL বা লিংক ভুল হয়েছে।
	• 500 Error: ব্যাকএন্ড সার্ভার বা MySQL কুয়েরিতে সমস্যা হয়েছে।
	• CORS Error: ব্যাকএন্ডে cors প্যাকেজ চালু করা নেই।
• Preview/Response ট্যাব। লাল রিকোয়েস্টটিতে ক্লিক করে পাশের Preview বা Response ট্যাবে গেলে ব্যাকএন্ড থেকে আসা আসল এরর মেসেজটি দেখা যায়।

৩. VS Code টার্মিনাল (Terminal) চেক করা — কম্পাইল বা ইমপোর্ট এররের জন্য

• লাল দাগ ও টার্মিনাল। কোনো প্যাকেজ ইনস্টল না থাকলে, ফাইলের নাম ভুল লিখলে বা ব্র্যাকেট ({ } বা ( )) ঠিকমতো বন্ধ না করলে VS Code-এর নিচে টার্মিনালে লাল রঙের এরর দেখাবে এবং ব্রাউজারে কালো পর্দায় এরর মেসেজ ভাসবে।
• সমাধান। টার্মিনালে দেখানো ফাইল ও লাইন নম্বরে গিয়ে বানান বা ইমপোর্ট পাথ (./ বা ../) ঠিক করলেই এটি সেরে যাবে।
