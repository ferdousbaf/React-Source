ছবিতে থাকা সবুজ বাটনটির লেখা হলো Add a README (আপনি যেটিকে "Add me Read" লিখেছেন)। এটি মূলত আপনার প্রজেক্ট বা রিপোজিটরির পরিচিতিমূলক একটি নোট বা নির্দেশিকা ফাইল (README.md) যোগ করার অপশন।

Add a README কী এবং কেন ব্যবহার করা হয়?

• প্রজেক্টের বিবরণ। এটিকে একটি বইয়ের মলাট বা ভূমিকা (Introduction) হিসেবে ভাবতে পারেন। অন্য কোনো ডেভেলপার বা ক্লায়েন্ট যখন আপনার এই প্রজেক্টে ঢুকবেন, তখন প্রথমেই এই লেখাটি দেখতে পাবেন।
• কী কী লেখা থাকে। সাধারণত এই ফাইলে প্রজেক্টটির নাম, এটি কী কাজ করে, কী কী প্রযুক্তি (যেমন: React, MySQL) ব্যবহার করা হয়েছে এবং কীভাবে প্রজেক্টটি রান করতে হয় তার সংক্ষিপ্ত নির্দেশনা লেখা থাকে।
• বাধ্যতামূলক কি না। এটি যোগ করা একদমই বাধ্যতামূলক নয়। না দিলেও আপনার কোড বা ফাইলের কোনো সমস্যা হবে না।

কীভাবে এটি যোগ করবেন?

• সরাসরি GitHub থেকে। ছবির ওই সবুজ Add a README বাটনে ক্লিক করলে একটি টেক্সট বক্স খুলবে। সেখানে প্রজেক্ট সম্পর্কে দুই-চার লাইন লিখে ডানপাশে Commit changes বাটনে ক্লিক করলেই এটি যুক্ত হয়ে যাবে।
• VS Code থেকে। আপনার কম্পিউটারের প্রজেক্ট ফোল্ডারে README.md নামে একটি ফাইল তৈরি করে কিছু লিখুন এবং সাধারণ নিয়মে git add ., git commit, ও git push করলেও এটি এখানে চলে আসবে।
