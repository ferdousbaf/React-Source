ধাপ ১: প্রাথমিক প্রস্তুতি (সফটওয়্যার ও অ্যাকাউন্ট)

কম্পিউটার থেকে কোড গিটহাবে পাঠানোর জন্য দুটি জিনিস প্রয়োজন— আপনার পিসিতে Git সফটওয়্যার এবং অনলাইনে একটি GitHub অ্যাকাউন্ট।
• Git ডাউনলোড ও ইনস্টল: প্রথমে Git অফিশিয়াল ওয়েবসাইট( https://git-scm.com/ ) থেকে আপনার অপারেটিং সিস্টেম (Windows/Mac) অনুযায়ী সফটওয়্যারটি ডাউনলোড করে সাধারণ সফটওয়্যারের মতো ইনস্টল করে নিন।
• GitHub অ্যাকাউন্ট তৈরি: ব্রাউজারে GitHub.com ওয়েবসাইটে গিয়ে Sign up বাটনে ক্লিক করুন। আপনার ইমেইল, একটি পাসওয়ার্ড এবং ইউনিক ইউজারনেম দিয়ে অ্যাকাউন্ট খুলে নিন।

ধাপ ২: পিসির সাথে GitHub অ্যাকাউন্টের পরিচয় করিয়ে দেওয়া (শুধু প্রথমবার)- গিট (Git) সেটআপ করা

আপনার পিসি থেকে কে কোড পাঠাচ্ছে তা গিটহাবকে চিনিয়ে দেওয়ার জন্য নিচের কমান্ড দুটি টার্মিনালে একে একে রান করুন (এটি জীবনে একবার করলেই চলে):

git config --global user.name "আপনার-গিটহাব-ইউজারনেম"
git config --global user.email "আপনার-গিটহাব-ইমেইল"

৬. যদি ফোল্ডারটি আগে থেকেই গিটাবের সাথে যুক্ত থাকে

আপনি যদি ইতিমধ্যে কোনো প্রজেক্ট গিটাবে আপলোড করে থাকেন এবং এখন সেই ফোল্ডারে নতুন একটি .txt ফাইল (যেমন notes.txt) যোগ করতে চান, তবে নিচের কমান্ডগুলো রান করুন।
• ফাইল তৈরি করা: VS Code-এ আপনার প্রজেক্ট ফোল্ডারের ভেতরে git-info.txt নামে ফাইলটি তৈরি করে কিছু লিখুন এবং সেভ (Ctrl + S) করুন।
• টার্মিনালে কমান্ড রান করা: টার্মিনাল (Ctrl + ~) ওপেন করে নিচের তিনটি কমান্ড একে একে দিন।bash

git add git-info.txt
git commit -m "Added git-info.txt file"
git push

• (নোট: আপনি যদি নির্দিষ্ট একটি ফাইলের বদলে ফোল্ডারের সব ফাইল একসাথে পাঠাতে চান, তবে git add git-info.txt-এর বদলে git add . লিখবেন।)


ধাপ ৭: পুরাতন প্রজেক্টে নতুন ফাইল যোগ বা কোড পরিবর্তন করলে কী করবেন?

আপনি যদি ইতিমধ্যে কোনো প্রজেক্ট গিটহাবে আপলোড করে থাকেন এবং পরে সেখানে নতুন কোনো ফাইল (যেমন: git-info.txt) যোগ করেন বা কোড এডিট করেন, তবে নতুন করে আর git init বা remote add দিতে হবে না।
ফাইলটি সেভ (Ctrl + S) করে টার্মিনালে শুধু নিচের ৩টি কমান্ড রান করলেই আপডেট হয়ে যাবে:

git add .
git commit -m "Added git-info.txt file"
git push

(নোট: আপনি যদি সব ফাইলের বদলে নির্দিষ্ট একটি ফাইল পাঠাতে চান, তবে git add . এর বদলে git add git-info.txt লিখবেন।)


গুরুত্বপূর্ণ সতর্কতা

• ফাইলের সাইজ: গিটাবে সাধারণ কমান্ডের মাধ্যমে সর্বোচ্চ ১০০ মেগাবাইট (100 MB) পর্যন্ত একটি ফাইল আপলোড করা যায়।
 সাধারণ .txt ফাইল কয়েক কিলোবাইট বা মেগাবাইটের হয়, তাই কোনো সমস্যা হবে না।
• ফাইলের নামে স্পেস: ফাইলের নামে স্পেস থাকলে (যেমন my note.txt) কমান্ড লেখার সময় ফাইলের নামটি ডাবল কোটেশনের ভেতরে লিখতে হবে। 
যেমন: git add "my note.txt"।
• লিংক কপি করার সতর্কতা: গিটহাব থেকে লিংক কপি করার সময় খেয়াল রাখবেন লিংকের শেষে যেন .git লেখাটি থাকে। যেমন: https://github.com।


 -------------------- Authorize git-ecosystem--------------

ছবিতে থাকা সবুজ রঙের Authorize git-ecosystem বাটনে ক্লিক করুন। এটি মূলত আপনার কম্পিউটারকে আপনার GitHub অ্যাকাউন্টে কোড আপলোড করার চূড়ান্ত অনুমতি (Permission) দেওয়ার জন্য এসেছে।

এটি কেন আসছে?

• নিরাপত্তা যাচাই (Security Verification)। আপনি টার্মিনালে সব কমান্ড ঠিকঠাক দিলেও, GitHub নিশ্চিত হতে চায় যে আপনার পিসি থেকে অন্য কেউ নয় বরং আপনি নিজেই (ferdousbaf) ফাইলগুলো আপলোড করছেন।
• শুধু প্রথমবারের জন্য। পিসিতে নতুন করে Git সেটআপ করার পর প্রথমবার git push কমান্ড দিলে এই পেজটি আসে। একবার অনুমতি দিয়ে দিলে পিসি আপনার লগ-ইন তথ্য সেভ করে রাখবে এবং ভবিষ্যতে আর এটি আসবে না।

এখন আপনার করণীয়

• সবুজ বাটনে ক্লিক করুন। পেজটিতে থাকা Authorize git-ecosystem বাটনে ক্লিক করুন (প্রয়োজনে GitHub-এর পাসওয়ার্ড চাইলে তা দিন)।
• ট্যাবটি বন্ধ করুন। ক্লিক করার পর ব্রাউজারে Authentication succeeded লেখা দেখালে ট্যাবটি কেটে দিন।
• VS Code চেক করুন। টার্মিনালে ফিরে এসে দেখবেন আপনার ফাইলগুলো সফলভাবে GitHub-এ আপলোড হয়ে গেছে।
বাটনে ক্লিক করার পর আপনার GitHub রিপোজিটরি পেজটি রিলোড (Refresh) করে দেখুন ফাইলগুলো দেখা যাচ্ছে কি না।

বুজ বাটনটি কাজ না করার কারণ হলো পেজটি পুরোপুরি লোড হওয়ার আগেই আপনি দ্রুত স্ক্রল করেছেন বা কোনো ব্রাউজার এক্সটেনশন বাটনটি ব্লক করছে। নিরাপত্তার কারণে GitHub পেজ লোড হওয়ার পর ২-৩ সেকেন্ড বাটনটি হালকা বা নিষ্ক্রিয় (Disabled) রাখে, যাতে কেউ ভুল করে ক্লিক না করে ফেলে।

http://127.0.0.1:2707 জিনিসটা কী?

• লোকাল কম্পিউটারের ঠিকানা। 127.0.0.1 হলো আপনার নিজের কম্পিউটারের লোকাল অ্যাড্রেস (Localhost) এবং 2707 হলো একটি পোর্ট নম্বর।
• কাজের ধরন। আপনি যখন সবুজ বাটনে ক্লিক করবেন, তখন GitHub এই ঠিকানার মাধ্যমে আপনার VS Code-এর টার্মিনালকে সিগন্যাল পাঠাবে যে অনুমতি দেওয়া হয়েছে। ফলে টার্মিনালে আটকে থাকা git push কাজটি তখনই সম্পন্ন হবে।

বাটন কাজ না করলে বা পপ-আপ না সরলে করণীয়

• পেজ রিলোড (Refresh) করে ২ সেকেন্ড অপেক্ষা করুন। ব্রাউজারের রিলোড বাটনে (F5 বা Ctrl + R) চাপ দিন। পেজটি আসার পর মাউস না নাড়িয়ে ২-৩ সেকেন্ড অপেক্ষা করলে দেখবেন সবুজ রঙটি আরও গাঢ় হয়ে গেছে, তখন ক্লিক করুন।
• অ্যাড-ব্লকার (Ad-blocker) বন্ধ রাখুন। ব্রাউজারে কোনো Ad-blocker বা প্রাইভেসি এক্সটেনশন চালু থাকলে সাময়িকভাবে বন্ধ করে রিলোড দিন।
• বিকল্প উপায় (যদি ব্রাউজারে কাজ না-ই করে)। ব্রাউজার ট্যাবটি কেটে দিন এবং VS Code-এর টার্মিনালে গিয়ে Ctrl + C চেপে আগের কমান্ডটি বাতিল করুন। এরপর আবার git push -u origin main কমান্ডটি রান করলে টার্মিনালেই Sign in with a code নামে একটি অপশন পাবেন, যেখান থেকে ৮ ডিজিটের একটি কোড ব্রাউজারে বসিয়ে সহজেই লগ-ইন করতে পারবেন।
পেজটি রিলোড করে ২ সেকেন্ড অপেক্ষা করার পর কি সবুজ বাটনটি কাজ করেছে, নাকি টার্মিনালের বিকল্প কোড পদ্ধতিটি দেখিয়ে দেব


অভিনন্দন! আপনার কম্পিউটারের সাথে GitHub অ্যাকাউন্টের সংযোগ বা অথেনটিকেশন (Authentication) সফলভাবে সম্পন্ন হয়েছে। ছবিতে থাকা Authentication Succeeded মেসেজটি সেটিই নিশ্চিত করছে।

এখন আপনার করণীয়

• ব্রাউজার ট্যাবটি বন্ধ করুন। স্ক্রিনের বার্তা অনুযায়ী (You may now close this tab) আপনি এই ব্রাউজার ট্যাবটি কেটে দিতে পারেন।
• VS Code-এর টার্মিনাল চেক করুন। আপনার VS Code-এ ফিরে গেলে দেখবেন টার্মিনালে আটকে থাকা git push কমান্ডটি নিজে থেকেই রান হয়ে ফাইল আপলোড সম্পন্ন করে ফেলেছে।
• GitHub রিপোজিটরি চেক করুন। ব্রাউজারে আপনার GitHub প্রোফাইলের রিপোজিটরি পেজটি রিলোড (Refresh) করলেই আপনার আপলোড করা ফাইলগুলো দেখতে পাবেন।
ভবিষ্যতে এই পিসি থেকে আর কখনোই নতুন করে লগ-ইন বা অথেনটিকেশন করতে হবে না। আপনি এখন থেকে সরাসরি git add, git commit, এবং git push কমান্ড দিয়ে কাজ করতে পারবেন।

আমি এখন নতুন কিছু এই ফাইল এ যোগ করতে চাই - git-info.txt file এ  আগের লিখার সাথে নতুন লিখা এড করতে চাই। কি করব?
 ধাপে ধাপে বলে দাও। আর অন্য আরো ৩টি ফাইল আপ্লোড দিতে চাই কি করব?
 যেহেতু আপনার ফোল্ডারটি ইতিমধ্যেই GitHub-এর সাথে যুক্ত হয়ে গেছে, তাই এখন ফাইল এডিট করা বা নতুন ফাইল যোগ করা খুবই সহজ। আপনাকে নতুন করে git init বা remote add দিতে হবে না, শুধু ৩টি কমান্ড রান করলেই পুরাতন ফাইলের আপডেট এবং নতুন ৩টি ফাইল একসাথে GitHub-এ আপলোড হয়ে যাবে।
ধাপে ধাপে পুরো প্রক্রিয়াটি নিচে দেওয়া হলো:

ধাপ ১: পুরাতন git-info.txt ফাইলে নতুন লেখা যোগ করা

• ফাইলটি খুলুন। VS Code-এর বামপাশের Explorer প্যানেল থেকে git-info.txt ফাইলটিতে ক্লিক করে ওপেন করুন।
• লেখা পেস্ট ও সেভ করুন। আগের লেখাগুলোর নিচে নতুন ইনস্ট্রাকশনগুলো কপি করে পেস্ট করুন। এরপর কিবোর্ড থেকে Ctrl + S চেপে ফাইলটি অবশ্যই সেভ করুন (ফাইল নামের পাশে সাদা গোল চিহ্নটি চলে গেলে বুঝবেন সেভ হয়েছে)।

ধাপ ২: নতুন ৩টি ফাইল তৈরি বা ফোল্ডারে রাখা

• ফাইল যোগ করুন। আপনি যে নতুন ৩টি ফাইল আপলোড করতে চান, সেগুলো সরাসরি আপনার পিসির ওই প্রজেক্ট ফোল্ডারের ভেতরে কপি করে রাখুন
 অথবা VS Code-এর New File আইকনে ক্লিক করে ফাইল ৩টি তৈরি করুন।
• সেভ নিশ্চিত করুন। প্রতিটি ফাইলের কাজ শেষ হলে Ctrl + S চেপে সেভ করে নিন।

ধাপ ৩: টার্মিনালে ৩টি কমান্ড রান করে আপলোড করা

VS Code-এ টার্মিনাল (Ctrl + ~) ওপেন করে নিচের ৩টি কমান্ড সিরিয়াল অনুযায়ী একটির পর একটি দিয়ে Enter চাপুন:
• ১. সব পরিবর্তন ও নতুন ফাইল একসাথে সিলেক্ট করা। এই কমান্ডের শেষে একটি ডট (.) আছে, যা আপনার এডিট করা git-info.txt এবং নতুন ৩টি ফাইল—সবগুলোকে একসাথে আপলোডের জন্য প্রস্তুত করবে।

git add .

• ২. আপডেটের একটি নোট (Commit) সেভ করা। আপনি কী পরিবর্তন করলেন তা সংক্ষেপে লিখে সেভ করুন।

git commit -m "Updated git-info.txt and added 1 new text files"

• ৩. GitHub-এ পাঠিয়ে দেওয়া (Push)। এবার নিচের কমান্ডটি দিলেই সব ফাইল অনলাইনে আপলোড হয়ে যাবে (এবার আর ব্রাউজার পপ-আপ আসবে না)।bash

git push


কীভাবে বুঝবেন কাজ হয়েছে?

• GitHub চেক করুন। টার্মিনালে আপলোড শেষ হওয়ার পর ব্রাউজারে আপনার GitHub রিপোজিটরি পেজটি রিলোড (Refresh) করুন। সেখানে আপনার নতুন ৩টি ফাইল দেখতে পাবেন এবং git-info.txt ফাইলে ক্লিক করলে আগের ও নতুন সব লেখা একসাথে দেখতে পাবেন।
