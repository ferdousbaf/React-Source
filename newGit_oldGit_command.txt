
১. নতুন রিপোজিটরি (New Repository) তৈরি করলে

কম্পিউটারে নতুন কোনো প্রজেক্ট বানিয়ে প্রথমবার গিটহাবে আপলোড করার সময় নিচের সবগুলো কমান্ড মাত্র একবার দিতে হয়:
• git init: কম্পিউটারের ফোল্ডারটিকে গিট প্রজেক্ট হিসেবে তৈরি করে।
• git add .: সব ফাইল আপলোডের জন্য প্রস্তুত করে।
• git commit -m "...": ফাইলগুলোর একটি সেভ পয়েন্ট বা নোট তৈরি করে।
• git branch -M main: মূল ব্রাঞ্চের নাম main সেট করে।
• git remote add origin ...: কম্পিউটারের ফোল্ডারটির সাথে গিটহাবের অনলাইন লিংক যুক্ত করে।
• git push -u origin main: ফাইলগুলো অনলাইনে আপলোড করে।

২. পুরনো প্রজেক্টে (Old Project) কাজ করলে

প্রজেক্ট একবার গিটহাবের সাথে যুক্ত হয়ে গেলে পরবর্তীতে কোডে যেকোনো পরিবর্তন এনে আপডেট পাঠাতে শুধু নিচের ৩টি কমান্ড দিলেই চলে:
• git add .
• git commit -m "আপনার পরিবর্তনের বিবরণ"
• git push

একটি জরুরি সতর্কতা (আপনার ক্ষেত্রে প্রযোজ্য)

আপনি যেহেতু আগের ধাপে Download ZIP করে ফাইল নামিয়েছিলেন এবং ভেতরের .git ফোল্ডার ডিলিট করার কথা বলেছিলেন, তাই সেই ফোল্ডারটির সাথে গিটহাবের সংযোগ বিচ্ছিন্ন হয়ে গেছে।
• যদি আপনি Download ZIP করা ফোল্ডারে কাজ করেন: গিটহাবের সাথে সংযোগ না থাকায় আপনাকে আবার প্রথমবারের মতো git init এবং git remote add origin কমান্ডগুলো দিয়ে নতুন করে সংযোগ তৈরি করতে হবে।
• যদি আপনি git clone করে প্রজেক্ট নামান: তবে আর git init বা remote add করতে হবে না, সরাসরি ৩টি কমান্ড (add, commit, push) দিয়েই কাজ করতে পারবেন।
